ASP.NET Core · PostgreSQL

Один интервал, одна бронь

Ограничение PostgreSQL запрещает пересечение активных интервалов одного ресурса. В рабочем календаре можно отправить 20 одновременных запросов и увидеть ответы сервера.

SignalR

Слот обновляется у всех

После изменения календаря сервер уведомляет открытые вкладки организации. Участники видят актуальную доступность на той же неделе.

RabbitMQ · Transactional Outbox

Резерв для следующего в очереди

Когда время освобождается, следующий участник получает резерв на 10 минут. Событие уведомления сохраняется вместе с резервом и отправляется с повтором при сбое.
